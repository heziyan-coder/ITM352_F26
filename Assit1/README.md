1. Data Structure Justification

The data structure that I store the questions for quiz in is the dictionary in json file. There is a list of answers and explanation for each question. So it's easy to read, easy to edit. Also, I can easily add or delete questions without changing main code in python.

2. Function Design

The function that I used to pick 5 random questions from question file is prepare_questions(). This is so that it will be different every time. And it can be more than 5 questions. Besides that, I used ask_question() to check the answers and show the explanations.

3. Control Flow

 I used while loop for the check of user's answer. If the user input is not valid, the program will ask again. The while loop will stop when the user input is valid. That way, the score won't be affected by the invalid input.
